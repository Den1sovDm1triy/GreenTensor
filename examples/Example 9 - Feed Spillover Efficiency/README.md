# Example 9 — Перехват мощности облучателя раскрывом (spill-over)

Демонстрация модуля `green_tensor/feed.py`.

Идея: интеграл нормированной ДН облучателя по конусу полуугла θ₀ даёт долю
мощности первичного источника, попадающую в раскрыв (линзу):

    η₁(θ₀) = ∫₀^θ₀ |F(θ)|² sinθ dθ / ∫₀^π |F(θ)|² sinθ dθ

Геометрическая связь: θ₀ = arcsin(a/d) — полуугол, под которым линза радиуса a
видна из фазового центра облучателя на расстоянии d от её центра.

Опорные точки (внутренние арбитры корректности, см. `tests/test_feed.py`):

| Проверка | Значение |
|---|---|
| η₁ элемента Гюйгенса, полусфера (θ₀ = 90°, облучатель на поверхности линзы) | 7/8 = **0.875** — канон диссертации (формула eq:eta1-spillover, расчёт `coef_n.xmcd`) |
| Замкнутая форма для ЭГ | η₁ = (8 − (1 + cos θ₀)³)/8 |
| Узкий конус (θ₀ → 0) | η₁ → D·(1 − cos θ₀)/2 — интеграл напрямую измеряет КНД (для ЭГ D = 3) |
| Конус 5° | η₁^(ЭГ) = 0.0057; соответствует d/a ≈ 11.47 |

Запуск:

```bash
python3 feed_spillover.py
```

Выход: таблица η₁(θ₀) для элемента Гюйгенса и элементарного вибратора +
рисунок `spillover_efficiency.png/.pdf` (ДН облучателей и кривые η₁(θ₀)
с отмеченным каноном 0.875 и точкой конуса 5°).

Тот же расчёт доступен в GreenTensor Studio (greentensor.ru/studio.html) —
эталонная задача «Раскрыв облучателя (spill-over η₁)» в группе «Демонстрации».
