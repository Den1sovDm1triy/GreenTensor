# Example 10 — Нейросетевая идентификация параметров покрытия

Пример показывает, как GreenTensor превращает **обратную** задачу
радиодиагностики покрытий в задачу обучения с учителем.

Библиотека считает **прямую** задачу — спектр обратного рассеяния (ЭПР)
проводящей сферы с магнитодиэлектрическим (радиопоглощающим) покрытием.
Нейросеть учится обращать этот спектр: по нему восстанавливает толщину
покрытия и его комплексные ε, μ.

- **Вход** сети — спектр `lg Q_back` в 32 точках по `k0·R`.
- **Выход** — 5 параметров покрытия: `t/R`, `ε′`, `ε″`, `μ′`, `μ″`.

Скрипт `nn_coating_identification.py` считает прямой отклик для нескольких
представительных покрытий (быстрая двойная точность) и печатает постановку
обратной задачи. Полная воспроизводимая выборка (6000 конфигураций), опорная
обратная сеть и исследование устойчивости лежат в **отдельном открытом
репозитории** (ссылка ниже).

## Запуск / Run

```bash
python3 nn_coating_identification.py
```

Вывод: таблица «покрытие → диапазон спектра» и постановка задачи
«спектр → параметры».

## Как этим пользоваться

1. **Посмотреть прямой отклик.** Функция `backscatter_spectrum(p)` по
   параметрам покрытия `p = (t/R, ε′, ε″, μ′, μ″)` возвращает спектр
   `lg Q_back` — это ровно то, что подаётся на вход сети.
2. **Сгенерировать свою выборку.** Меняйте список `CASES` или подавайте свои
   параметры в `backscatter_spectrum` — так строятся пары «спектр → параметры».
   Для сильных потерь GreenTensor автоматически переходит на арифметику
   повышенной точности (медленнее); полный датасет собран быстрым решателем
   из внешнего репозитория.
3. **Обучить/применить сеть.** Готовый датасет, опорная сеть
   (`train_inverse.py`) и метрики — во внешнем репозитории; клонируйте его и
   запускайте оттуда.

## English (short)

Neural-network identification of a magnetodielectric coating on a PEC sphere
from its monostatic back-scattering spectrum. GreenTensor provides the forward
map (parameters → spectrum); the network learns the inverse (spectrum →
parameters: `t/R`, `ε′`, `ε″`, `μ′`, `μ″`). This folder is a light demo; the
full 6000-sample dataset, the reference inverse MLP and the robustness study
live in a separate open repository:
**https://github.com/Den1sovDm1triy/rpm-coating-inverse-dataset** (MIT).
