# Пример 7. Ненормированные характеристики поля и диаграмма направленности линзовой антенны

Расчёт **абсолютных** (ненормированных) значений напряжённости поля многослойных
сферических тел методом тензорных функций Грина и верификация полноволновым
методом конечных элементов (Ansys HFSS).

Итоговый документ — [`Example7_verification.pdf`](Example7_verification.pdf)
(исходник `Example7_verification.tex`).

## Что проверено

**Задача дифракции** — семь конфигураций, 28 диаграмм:

| Тело | `k0a` | Медиана расхождения |
|---|---|---|
| Проводящая сфера | 0,5 / 2 / 15 | 0,31 / 0,10 / 0,49 дБ |
| Сфера с диэлектрическим укрытием | 0,5 / 2 / 15 | 0,25 / 0,14 / 0,45 дБ |
| Линза Люнеберга (5 слоёв) | 15 | 0,63 дБ |

По всем 28 диаграммам медиана поточечного расхождения 0,40 дБ, медиана
расхождения максимумов 0,23 дБ. Ближняя зона — 0,24 дБ по семи конфигурациям.

**Антенная задача** — линза Люнеберга, `k0a = 15`, облучатель на поверхности:
расхождение максимумов −0,37 дБ при абсолютном уровне 4,531 против 4,342 В/м,
медиана по лепесткам 0,47 дБ (E-плоскость) и 0,64 дБ (H-плоскость).

Все величины абсолютные: приведение кривых к максимуму не применялось.

## Используемые функции библиотеки

```python
import green_tensor as gt

gt.far_field_sphere(...)            # ненормированное поле дальней зоны, В/м
gt.bistatic_rcs_sphere(...)         # абсолютная бистатическая ЭПР, м²
gt.external_field_sphere(...)       # точный радиальный ряд, r > a
gt.magnetic_field_sphere(...)       # магнитное поле того же ряда
gt.antenna_pattern_sphere(...)      # ДН линзовой антенны
```
