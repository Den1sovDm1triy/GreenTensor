# Порядок воспроизведения

Все результаты документа воспроизводятся четырьмя скриптами. Эталонные данные
Ansys HFSS уже лежат в `reference/` — полноволновой пакет для повторения расчёта
не требуется.

## Требования

Python 3.10+, `numpy`, `scipy`, `matplotlib`. Библиотека вызывается из корня
репозитория, поэтому запускать скрипты следует из каталога примера:

```bash
cd "examples/Example 7 - Absolute fields and lens antenna"
```

## 1. Расчёт методом ТФГ

```bash
python3 absolute_fields.py
```

Считает диаграммы, карты ближней и дальней зоны для всех конфигураций и
записывает в `data/`:

* `far_<тело>_k<размер>_diffraction.csv` — ненормированные диаграммы, В/м:
  столбцы `theta_deg`, `E_co_Eplane_Vm`, `E_co_Hplane_Vm`, `E_cross_Vm`,
  `E_op_Vm`, `E_kp_Vm`;
* `resources.json` — время, пиковая память, `N_max`, контрольные величины.

Вспомогательные картинки по каждой конфигурации складываются в `figures/aux/`
и в документ не входят.

## 2. Круговые диаграммы, задача дифракции

```bash
python3 figures_polar.py
```

Строит `figures/pol_<тело>_k<размер>_diffraction.png` — по четыре диаграммы на
конфигурацию (вертикальная, горизонтальная, основная и кросс-поляризация
круговой волны) и записывает метрики сверки в `data/polar_metrics.json`.
Печатает таблицу расхождений, воспроизводящую таблицу 3 документа.

## 3. Ближняя зона

```bash
python3 near_verify.py
```

Сравнивает амплитуду рассеянного поля на сетке 141×141 в плоскости `xz` с
эталоном по комплексным компонентам. Строит `figures/near_cmp_vec.png`,
записывает `data/near_metrics.json`, печатает таблицу 2 документа.

## 4. Диаграмма направленности линзовой антенны

```bash
python3 figures_antenna.py
```

Считает ДН по соотношению взаимности (`gt.antenna_pattern_sphere`) и строит
`figures/pol_luneburg_k15_antenna.png`. Печатает расхождения таблицы 4.

## 5. Сборка документа

```bash
pdflatex Example7_verification.tex   # трижды, для перекрёстных ссылок
```

Рисунки берутся из `figures/` и `reference/screens/`.

## Автоматические проверки

Расчётные соотношения покрыты тестами библиотеки:

```bash
python3 tests/run_all.py            # из корня репозитория
```

Антенной задаче отвечает `tests/test_antenna_reciprocity.py`: сверка магнитного
поля с `∇×E`, соотношение исходящей волны в дальней зоне, предельный переход к
кардиоиде в свободном пространстве и сверка ДН с эталоном из `reference/csv/`.

## Эталонные данные

```
reference/csv/          hfss_far_*     диаграммы, rE [В] на r = 10 м
                        hfss_circ_*    круговая поляризация, rELHCP/rERHCP
                        hfss_nearvec_* ближняя зона, комплексные Ex,Ey,Ez
                        hfss_src_freespace.csv  облучатель без тела
reference/screens/      модели в окне трёхмерного моделирования
reference/profiles/     тетраэдры и пиковая память по конфигурациям
reference/run_summary.json  затраты обоих методов и вычислительные платформы
reference/hfss_src_calib.json  калибровка облучателя
reference/MODELS.md            описание эталонных моделей и экспорта
reference/scripts/             автоматизация Ansys HFSS (PyAEDT)
```

Величины `rE` пересчитываются в напряжённость поля как `|E| = rE / r` при
`r = 10` м.
