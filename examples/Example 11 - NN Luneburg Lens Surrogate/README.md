# Example 11 — Нейросетевой суррогат линзы Люнеберга

Пример показывает **прямое** (суррогатное) направление: GreenTensor считает
сечения рассеяния четырёхслойной линзы Люнеберга, а нейросеть учится
воспроизводить их прямо по проницаемостям слоёв — заменяя полноволновой
расчёт в цикле оптимизации откликом за микросекунды.

    параметры (k0a, ε1..ε4)  →  (Q_sca, log10 Q_back)

- **Вход** сети — электрический размер `k0a` и четыре проницаемости `ε1..ε4`.
- **Выход** — полное сечение рассеяния `Q_sca` и логарифм обратного
  сечения `log10 Q_back`.

Скрипт `nn_luneburg_surrogate.py` считает отклик для нескольких линз и печатает
постановку суррогатной задачи. Полная воспроизводимая выборка (6000
конфигураций), опорная сеть-суррогат и скрипты — в **отдельном открытом
репозитории** (ссылка ниже).

## Запуск / Run

```bash
python3 nn_luneburg_surrogate.py
```

Вывод: таблица «конфигурация → сечения» и постановка задачи
«профиль → характеристики».

## Как этим пользоваться

1. **Посмотреть прямой расчёт.** Функция `cross_sections(p)` по параметрам
   линзы `p = (k0a, ε1..ε4)` возвращает `(Q_sca, log10 Q_back)` — это то, что
   сеть-суррогат учится предсказывать.
2. **Сгенерировать свою выборку.** Меняйте `CASES` или подавайте свои профили
   (проницаемости убывают от центра к поверхности — класс Люнеберга); так
   строятся пары «профиль → характеристики».
3. **Обучить/применить суррогат.** Готовый датасет, опорная сеть и метрики —
   во внешнем репозитории; клонируйте его и запускайте оттуда.

## Внешний репозиторий с датасетом

Полный датасет **LL-Surrogate-6000**, обучающие скрипты и метрики:

## English (short)

Neural-network **surrogate** of a four-layer Luneburg lens. GreenTensor gives
the forward map (layer permittivities → cross sections); the network learns to
reproduce it, replacing the full-wave solver inside an optimization loop. This
folder is a light demo; the full 6000-sample dataset, the reference surrogate
MLP and the scripts live in a separate open repository:
**https://github.com/Den1sovDm1triy/luneburg-lens-nn-dataset** (MIT).
